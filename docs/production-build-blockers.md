# Production build blocker fix

Branch: `codex/fix-production-build`, based on cash-handover commit `e3c719c746a12b2aad6f8c0304596d61d0ad741e` on GitHub main. Original unrelated reseller changes remain in their original working tree.

## Confirmed causes

1. Windows CRLF in App.jsx prevented the egress patch's LF anchors from matching. CRLF in the injected COE runtime also prevented the next patch's signatory-list anchors from matching.
2. Repeat builds applied the A4 patch to an already installed e-sign workflow. That workflow replaces the original PDF/Word builder buttons with its controlled workflow action; the A4/e-sign prerequisite checks still expected the original buttons.
3. COE address regression tests read an unprepared App.jsx, implicitly depending on a previous build. They now prepare A4 and e-sign prerequisites explicitly.

## Changes

- `scripts/supabase-egress-optimizer.cjs`: normalize incoming app CRLF before anchor matching.
- `scripts/coe-esign-workflow.cjs`: normalize app and injected runtime line endings; verify existing workflow before checking pre-install prerequisites.
- `scripts/coe-a4-pdf.cjs`: normalize app input and recognize installed e-sign builder actions while retaining A4/export verification.
- `tests/supabase-egress-optimizer.test.cjs`, `tests/coe-esign-workflow-patch.test.cjs`: CRLF and repeated-patch regressions.
- `tests/coe-a4-pdf-patch.test.cjs`: verify compatible controlled export action.
- `tests/coe-address-compensation.test.cjs`: explicit build prerequisite preparation.

No business UI, financial calculation, permissions, database object or migration was changed. Build-generated App.jsx edits were restored after validation; they remain generated by the existing build pipeline.

## Validation and results

- Standard `npm run build` passed from the untouched App.jsx checkout and passed again immediately afterward with generated patches already installed.
- 27 tests passed across egress, COE A4, e-signature, address/compensation, payroll deferral, cash handover and owner daily receipts. Tests also pass before running a build.
- `git diff --check` passed.
- Full `npm run lint` was executed: 357 errors and 16 warnings remain outside this fix. Repository-wide lint is not passing.
- Existing Vite large-chunk and ineffective-dynamic-import warnings remain. The build output is in `dist/` locally.

No GitHub push, deployment, Supabase migration or production-data modification was performed for this fix. Production behavior remains unverified until a separately authorized rollout.

Rollback: revert the local build-fix commit. No database rollback is required.
